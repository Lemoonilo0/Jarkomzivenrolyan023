Materi DNS

Pengertian DNS

Domain Name System (DNS) adalah sistem penamaan hirarki yang digunakan untuk mengidentifikasi komputer, layanan, dan sumber daya lain di Internet atau jaringan pribadi. DNS menerjemahkan nama domain yang mudah diingat ke alamat IP numerik.

Cara Kerja DNS

DNS bekerja melalui beberapa tahap: - DNS Query dari Client - DNS Resolver mencari cache - Root DNS Server - TLD DNS Server - Authoritative DNS Server

Jenis DNS Record

- A Record: Menghubungkan nama domain dengan alamat IPv4 - AAAA Record: Untuk alamat IPv6 - CNAME: Alias untuk nama domain - MX Record: Mail exchanger - NS Record: Nameserver records

DNS Server

Fungsi DNS Server

DNS Server berperan sebagai penerjemah antara nama domain dan alamat IP. Server ini menyimpan database nama domain dan alamat IP yang terkait.

Jenis DNS Server

1. Root DNS Server 2. TLD DNS Server 3. Authoritative DNS Server 4. Recursive DNS Server

Konfigurasi DNS Server

Meliputi setup zona DNS, konfigurasi record, pengaturan cache, dan implementasi keamanan DNS seperti DNSSEC.
